# Documentation Map

This folder keeps project documentation that supports planning, implementation, and portfolio explanation.

## Core Documents

* `project-brief.md` - Project purpose, Phase 1 MVP boundaries, non-goals, target audience, and success criteria.
* `tech-stack.md` - Technology choices and ownership boundaries between Unity, React, shared protocol, CI, and future backend work.
* `architecture.md` - Technical architecture details that become important during implementation.
* `code-standards.md` - Coding conventions, especially for Unity and C# work.
* `roadmap.md` - Longer-term milestones and portfolio direction.
* `decision-log.md` - Meaningful technical decisions and the reasoning behind them.

## Task Tracking

Jira is the source of truth for active tasks and backlog items. Avoid adding new task lists in this folder unless they are temporary notes that will be moved into Jira.

## Historical Notes

`weekly-reports/` contains historical progress notes. These can stay separate from the active planning docs.
